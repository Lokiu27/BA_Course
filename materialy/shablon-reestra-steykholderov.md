# Шаблон. Реестр стейкхолдеров и вопросов к бизнесу

Используется в [уроке 1.1](../modul-1/tema-1-kak-teper-rabotaet-razrabotka.md) и
пригодится в работе перед любым разговором с бизнесом.

Как пользоваться: скопируйте шаблон в свой конспект и заполните. Качество
результата проверяется по чек-листу в конце шаблона.

## 1. Идея заказчика

Опишите идею одним-двумя предложениями: что хотят сделать и в каких
рамках (сроки, ограничения).

> Пример: интернет-магазин запускает доставку день-в-день в крупных городах
> к высокому сезону; бюджет ограничен.

## 3. Реестр стейкхолдеров

Типы стейкхолдеров: **Р** — принимает решения, **П** — пользуется
результатом, **И** — исполняет работу, **Б** — может заблокировать.
Один стейкхолдер может иметь несколько типов.

| # | Роль | Кто это (должность или имя) | Типы | Проблема или риск для этой роли |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |
| … | | | | |

## Чек-лист самопроверки

- [ ] Охватаны все 4 типа стейкхолдеров, а не только руководитель и клиент.
- [ ] Для ключевых ролей указаны проблемы или риски, а не только названия.
- [ ] Вопросы адресованы конкретным ролям; нет вопросов «расскажите
      обо всём».
- [ ] Есть вопросы о границах изменения: что входит и что не входит.
- [ ] Метрика успеха проверяема по данным.
